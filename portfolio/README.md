# Prince Kofi Amissah Portfolio

Personal portfolio site for Prince Kofi Amissah, covering selected projects, skills, and contact links.

Live demo: https://prince-kofi-amissah.vercel.app

## Tech Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- Framer Motion

## Local Setup

```bash
npm install
npm run dev
```

Open http://localhost:3000.
